# H001 — Core wedge hypothesis

**Hypothesis:** Operationally complex organizations will pay for capability-level
incident decision analysis (blast radius + time-to-impact + minimum containment
set + evidence requests) even when they already own monitoring, ratings, and a CMDB
— because none of those produce a defensible, replayable decision artifact.

**Falsifier:** interviews/pilots show the case file is "interesting" but nobody
requests a second analysis or attaches budget (gate N-G fails).

**Status:** untested. Evidence gathering is gated on EXP-N006 and the manual pilot.
